Race Day Sign-Up is a PHP website where racers sign up for a race.
You fill out a form with your name, car, car number, and race class,
and it saves to a MySQL database. Then the Drivers page shows everyone
lined up by car number, like a starting grid.

I picked racing because I love it, especially Nascar. Before a real race, every driver has to sign up and get a number
so I turned that into my project.

Full setup steps and how the form works with the database are in
Race_Day.docx.
